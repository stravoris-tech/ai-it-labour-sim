# Sources

Every external source consulted for the model, grouped by what it was used for. Data were gathered on 9-10 October 2026. Phases 1-6 parameter values were illustrative first guesses, sized so the arithmetic is easy to check, and were not taken from these sources. Data entered the model in Phase 7: the 2024-2026 fit, the validation checks and the scenario settings. A few figures came only from press summaries; they are marked "unverified" and none of them is a fit target.
